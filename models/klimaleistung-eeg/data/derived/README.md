# Abgeleitete Datenbanken

## Enthalten

`smard_stundendaten_2021_2025.sqlite` ist ein reproduzierbarer SQLite-Snapshot
der SMARD-Marktdaten 2021–2025. Die SMARD-Marktdaten stehen unter CC BY 4.0.
Namensnennung: **Bundesnetzagentur | SMARD.de**.

## Lokal zu erzeugen

- `netztransparenz_eeg.sqlite`: aus manuell geladenen Jahresabrechnungs-ZIPs.
- `wetterdaten_szenarien.sqlite`: aus SMARD, Meteostat und den dokumentierten
  PV-/Wind-Modellannahmen.

Diese beiden Datenbanken werden bewusst nicht im Repository versioniert. Die
Erzeugung ist in der Haupt-README beschrieben.
