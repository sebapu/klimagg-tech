# Models

This directory contains transparent, reproducible analytical models that test
assumptions, effects, data requirements and implementation options related to
the Klima-Generationen-Gesetz (KlimaGG).

The models are not normative parts of the law and are not production services.
They provide evidence, scenarios and reference calculations that can inform the
legal design, public debate and later software specifications.

## Available models

- [`klimaleistung-eeg/`](klimaleistung-eeg/) – hourly climate-performance
  accounting, EEG financing analysis and a 2030 market scenario.

Future models should each use a separate subdirectory with their own README,
input-data documentation, reproducible scripts, model limits and citation
information.
